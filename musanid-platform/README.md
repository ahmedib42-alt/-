# منصة مُسانِد v2.5 | النسخة الأساسية المعيارية
### Musanid Platform - Special Education & Rehabilitation System (Base Edition)

---

## 🌟 نبذة عن المنصة
**منصة مُسانِد (v2.5)** هي نظام رقمي متكامل وشامل مُصمم خصيصاً لمساعدة معلمي ومختصي التربية الخاصة والتأهيل المهني في مراكز الرعاية النهارية والمدارس.
تتيح المنصة متابعة شاملة بزاوية 360 درجة للطلاب من ذوي الإعاقة (توحد، متلازمة داون، شلل دماغي، إعاقة ذهنية)، وتوثيق الجلسات التأهيلية، وتعديل السلوك، ورصد السلامة الجسدية، وجدولة المواعيد، والأرشفة الذكية للمستندات والخطط الفردية.

## 🏗️ البنية الهيكلية المعمارية (Modular Architecture)

تمت إعادة هيكلة المنصة من ملف أحادي ضخم إلى بنية معيارية نموذجية مطابقة لأفضل الممارسات البرمجية:

```
musanid-platform/
│
├── index.html                  # نقطة الدخول النظيفة وخفيفة الحجم (< 60 سطراً)
├── تشغيل_المنصة.bat            # ملف تشغيل فوري بنقرة واحدة لبيئة ويندوز
├── README.md                   # التوثيق الشامل ودليل الاستخدام
│
├── assets/                     # مجلد الهوية البصرية والوسائط
│   ├── logo.png                # الشعار الرسمي عالي الدقة (PNG)
│   └── logo.svg                # الشعار الرسمي بالصيغة المتجهة (SVG)
│
├── css/                        # مجلد التنسيقات والأنماط المعيارية
│   └── style.css               # المتغيرات اللونية، البطاقات التفاعلية، خريطة الجسد، وتنسيقات الطباعة
│
├── js/                         # الطبقات البرمجية المعيارية المقسمة حسب المسؤولية
│   ├── data.js                 # البيانات النموذجية الأولية والمصفوفات الأساسية
│   ├── store.js                # محرك إدارة الحالة والتخزين المحلي المزدوج والتنبيهات
│   ├── components.js           # واجهات بوابة الدخول، الترويسة، لوحة التحكم، والملف 360
│   ├── tracking.js             # أدوات الرصد: خريطة الجسد، الحمام، سلوك ABC، سجلات الحضور، والتقارير
│   └── app.js                  # المهام والرزنامة، الأرشيف الذكي، النسخ الاحتياطي، والموجّه الرئيسي
│
└── backup/                     # مجلد النسخ الاحتياطية المرجعية
    └── index_original_v2.5.html # النسخة الأصلية الكاملة المحفوظة بنسبة 1:1 للأمان التاريخي
```

## 🚀 كيفية التشغيل والتشغيل على فلاشة (USB Drive)

المنصة مصممة للعمل **بدون اتصال بالإنترنت (Offline-First)** وبدون الحاجة لتثبيت أي برامج أو خوادم (Zero Dependencies):

1. **طريقة التشغيل السريع (ويندوز):**
   - انقر نقراً مزدوجاً على الملف `تشغيل_المنصة.bat`.
   - ستفتح المنصة مباشرة في متصفح الويب الافتراضي لديك (Google Chrome, Microsoft Edge, Firefox, Brave).

2. **طريقة التشغيل المباشر:**
   - افتح ملف `index.html` في أي متصفح ويب حديث.

3. **التشغيل من فلاشة USB:**
   - انسخ المجلد كاملاً إلى أي وحدة تخزين خارجية (فلاشة) وافتح المنصة على أي جهاز حاسوب داخل المركز أو المدرسة دون أي إعداد مسبق.

| **القائمة الجانبية الذكية للطلبة** | قائمة جانبية سريعة مثبتة مع بحث فوري، اختيار مباشر للطالب، وإمكانية إضافة وحذف وتعديل الطلاب بسهولة مع زر إظهار/إخفاء |
| **ملف الطالب 360°** | بطاقة ذكية شاملة للطالب (البيانات الشخصية، جهات الاتصال، تغيير الصورة عبر السحب والإفلات، والخدمات النشطة) |

| **خريطة الجسد التفاعلية 2D** | واجهة تفاعلية ثنائية الأبعاد (أمامي/خلفي) لتثبيت نقاط الإصابات، الكدمات، وتوثيق السلامة الجسدية مع إمكانية إرفاق صور والطباعة |
| **تدريب الحمام والسوائل** | سجلات تفصيلية لعمليات التبول، الإخراج، الحوادث العارضة، ومتابعة ترطيب وشرب السوائل |
| **رصد السلوك 360° (ABC)** | تحليل إكلينيكي رصين للسلوك (المثير السابق A، السلوك B، النتيجة اللاحقة C) مع تحديد شدته والبيئة الصفية |
| **التقرير الشامل التراكمي** | تقرير طبي وتربوي متكامل للطالب قابل للمعاينة والطباعة الرسمية الفورية بنقرة واحدة |
| **إدارة المهام والرزنامة** | تقويم شهري تفاعلي مع لوحات مهام قابلة للطي (مهام اليوم، المهام القادمة، والمنجزة) |
| **الأرشيف الذكي والمستندات** | رفع وتصنيف واستعراض وتنزيل ملفات PDF، الصور، مقاطع الفيديو، والتقارير الطبية |

## 💾 محرك إدارة البيانات، التخزين الذكي والمزامنة (Smart Database & Sync Engine)

تم تزويد المنصة بنظام متقدم لإدارة وتخزين البيانات عبر ملف `js/db.js` و `js/store.js`:
1. **قاعدة بيانات معيارية `IndexedDB` عالية السعة:**
   - جداول مهيكلة للطلاب، المواعيد، الجلسات، لغة الجسد، السلوكيات، المهام، والأرشيف.
   - تجاوز قيود حجم التخزين القديمة (5MB) ليصبح قادراً على استيعاب مئات الميجابايت من السجلات والمستندات.
2. **تخزين ذكي مزدوج الطبقات (Dual-Layer Cache Architecture):**
   - استجابة فورية فائقة السرعة مع مزامنة آنية بين الذاكرة والـ LocalStorage والـ IndexedDB.
   - توافق عكسي 100% مع المفاتيح القديمة `mukhles_*` والمفاتيح الحديثة `musanid_*`.
3. **نقاط الاسترجاع السريعة (Snapshots Engine):**
   - أخذ لقطات تلقائية دورية في الخلفية كل 5 دقائق مع إمكانية أخذ لقطة يدوية بضغطة زر.
   - استرجاع فوري لأي نقطة زمنية سابقة بنقرة واحدة ودون الحاجة لملفات خارجية.
4. **طابور المزامنة التلقائية (Offline-First Sync Queue):**
   - العمل التام دون إنترنت مع تسجيل التعديلات في طابور محلي آمن ومزامنتها فور عودة الاتصال.
5. **فحص تكامل وسلامة البيانات (Data Integrity Diagnostics):**
   - فحص إكلينيكي للتأكد من ربط جميع الجلسات والمواعيد بطلاب مسجلين ومنع أي بيانات معلقة.
